# Robot storage manager (Phase 01)

Use the `rsm` command-line interface (CLI) or its Python library to scan local
robot recordings, maintain manifests, compute hashes, and plan retention.

Start with the [user guide](docs/user.md). For implementation details, see the
[technical guide](docs/technical.md). To set up and run the CLI, see
[run and test](docs/run-and-test.md).
